# #58 法国巴黎银行与创始人档案 (BNP Paribas & Michel Pébereau)

本目录收录《财富》世界500强 **第 58 位** —— 欧洲大陆资产规模第一大银行集团 **法国巴黎银行 (BNP Paribas S.A.)** 及其历史奠基机构 **巴黎国民贴现行 (CNEP)**、**巴黎巴银行 (Paribas)** 与世纪大并购掌舵人 **米歇尔·佩贝罗 (Michel Pébereau)** 的深度全景档案。
