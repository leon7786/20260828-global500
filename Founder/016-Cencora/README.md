# #16 Cencora 公司与百年医药流通奠基人档案 (Cencora & AmerisourceBergen Pioneers)

本目录收录《财富》世界500强 **第 16 位** —— **Cencora 公司 (原美源伯根 AmerisourceBergen)** 及其奠基人 **吕西安·布伦斯威格 (Lucien Brunswig)** 与 **罗伯特·卑尔根 (Robert Bergen)** 等先驱的深度全景档案。

---

## 📑 目录文档索引

1. 🏢 **[公司介绍 (Company Profile)](company.md)**
   - 核心商业版图（全美处方药分销超级网络、全球第一大特种药品与肿瘤药分销服务商 ION、欧洲 Alliance Healthcare 批发网络、World Courier 全球温控临床物流、Good Neighbor Pharmacy 独立药房联盟）
   - 核心竞争护城河（全美20-30%处方药流通掌控力、特种药与罕见病高壁垒分销生态、与沃博联 Walgreens 的世纪战略绑定、超大规模微利高效供应链）
   - 历史关键里程碑（百年药品批发起源、2001年美源与伯根布伦斯威格对等合并、收购 Alliance Healthcare、2023年全球品牌战略升级为 Cencora）
   - 企业文化与使命（“致力于创造更加健康的未来”、以患者为中心、供应链精准零容错）

2. 👤 **[奠基人与历史领军者人物志 (Founder & Pioneer Profile)](founder.md)**
   - 吕西安·拿破仑·布伦斯威格生平：从法国药房学徒到美国西部药品分销拓荒先驱
   - 1888年布伦斯威格药业 (Brunswig Drug Company) 创办与药品纯度检测/区域化冷链先河
   - 卑尔根兄弟 (Bergen Brothers) 创办 Bergen Drug：战后率先推行计算机穿孔卡片库存与高周转药房补货
   - 2001年世纪大合并：罗伯特·马蒂诺推动美源 (AmeriSource) 与伯根布伦斯威格对等重组诞生医药流通航母
   - 底层认知工具箱（高周转微利供应链飞轮、特种药高门槛粘性模型、全球临床温控冷链网络、生态结盟与战略共生）
   - 经典名言与重大历史年表
