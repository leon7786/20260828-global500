2. 👤 **[奠基人介绍 (Founder Profile)](founder.md)**

   - 标准石油时代的铁血管线大师：詹姆斯·C·唐奈尔 (J.C. Donnell) 从挖沟工到公司总裁
   - 1911年最高法院反垄断分拆：唐奈尔家族三代执掌马拉松60年的工业史诗
   - 发现全美产油神话“耶茨油田 (Yates Field)”与奠定中西部炼化管网版图
   - 从俄亥俄石油到马拉松石油，再到现代全美第一大独立炼油霸主 (MPC) 的世纪蜕变
   - 底层认知工具箱：逆境防御同盟、管网咽喉锁喉、超级主力油田深耕、炼化动态再平衡
