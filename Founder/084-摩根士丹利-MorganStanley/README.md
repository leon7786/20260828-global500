   - 1935年华尔街2号开天辟地：开业首年拿下全美 24% 承销份额的封神之战

   - 传承演进：从蓝血贵族合伙人制到戈尔曼时代的“万亿财富管理超级航母”
   - 底层认知工具箱（一级信誉即资本、反脆弱分拆、承销定价权、抗周期轻重资产平衡）
   - 经典名言金句、华尔街秘辛与生平大事年表
